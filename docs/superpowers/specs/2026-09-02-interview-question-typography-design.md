# 面试题目字号优化设计

**日期：** 2026-09-02

## 目标

降低面试页面题目标题的视觉重量，让较长的问题更适合连续阅读，同时保留页面的层级感。

## 范围

- 只调整 `frontend/app/interview/[id]/page.tsx` 使用的 `.mint-question-title`。
- 不改变首页主标题、报告页标题、答题输入框字号或业务逻辑。
- 保持桌面端和移动端都可读，不新增字号切换控件。

## 方案

将题目字号从 `clamp(32px, 4.8vw, 58px)` 调整为 `clamp(27px, 3vw, 40px)`，同时将行高改为 `1.25`、字距改为 `-0.04em`。这样桌面端最大字号从 58px 降到 40px，移动端仍保留足够的阅读层级，长问题会自然换行。

## 验收标准

1. 面试页题目使用新的字号范围，最大字号不超过 40px。
2. 首页和报告页现有字号不发生变化。
3. 前端测试和生产构建通过。
4. 工作区不产生 API Key 或其他敏感信息。
