## 基础层（v1 提案保留，作为证据地基）

1. **技能证据链下钻**：技能卡展开"这个等级怎么来的"——最近 3 次有效回答的题目、等级、点评一句话、场次链接。summary API 每技能查最近 3 条 valid run（约 30 行）。
2. **学习状态**：技能卡"已学/未学"角标（接入 skill_study_log）；薄弱且未学排最前。
3. **追问角度分布**：深挖对话中被数字质疑/假设变化/细节下钻的次数——表达弱点模式（数据：project_dialogs.heuristic_tag，fallback 不计）。

## 支柱一：记忆新鲜度（间隔重复建模）

**洞察：** 等级 4/4 是 90 天前挣的和昨天挣的，含义完全不同。现在的画像对时间不敏感——这是"成绩单"最大的失真。

**设计：**

- 每个技能按 `last_assessed_at` 计算新鲜度三档：
  - 🟢 **新鲜**（≤3 天）：等级可信
  - 🟡 **开始冷却**（4-10 天）：等级可能已衰减
  - 🔴 **生疏**（>10 天）：等级仅供参考，建议复习
- 技能卡等级旁显示新鲜度徽章；**薄弱项排序规则升级**：`薄弱 × 生疏` 的技能排最前（最危险组合）。
- readiness 计算引入衰减：超过 10 天未练的技能，等级按 0.8 折算后再加权——readiness 从静态分变成**随时间流逝自动下降的活指标**。用户两周不打开，准备度会真的掉，产生回来的动力。
- 收束句（摘要）同步提及最生疏的技能。

**数据：** 全部已有（last_assessed_at）。衰减系数为常量，不做配置（YAGNI）。

## 支柱二：面试日倒排计划（评估器 → 教练的跨越）

**洞察：** 备面者的真实问题是"我 X 月 X 日面试，今天该练什么？"——画像回答不了这个问题，所以它只是成绩单。

**设计：**

- 用户在画像页设置**目标面试日期**（存 `interview_targets.target_date`，迁移 0014 加一列）。
- 画像首屏从"readiness 卡"升级为**"今日训练卡"**：距面试 N 天 + 今天该做的 1-3 个动作。生成规则（纯规则引擎，动态计算，不持久化——**计划是活着的**，每次打开按当前状态重算）：

```
优先级排序（取前 1-3 个）：
1. 到期验证：practice_completed_at + 3 天已到、且未验证的技能 → "验证 XX"
2. 生疏薄弱：level < target 且 >10 天未练 → "复习 XX"
3. 未学薄弱：薄弱且无学习记录 → "学 XX（wiki）"
4. 常规薄弱：level < target → "专项练 XX"
5. 无薄弱：随机练一轮保持手感
```

- 倒排压力显示：距面试 ≤3 天时，训练卡改为"冲刺模式"文案（只推验证与最快提分项，不推新学习）；已过面试日则回到常规模式并提示更新日期。
- 每完成一个动作（评分/wiki 学习），今日卡自动重算——**画像页从"报告页"变成"每天的入口"**。

**数据：** 只加一个日期列。计划纯派生。

## 支柱三：练→验有效性度量（证明系统真的有用）

**洞察：** "专项练一次"按钮被点了很多次，但产品从没回答过：**练了到底有没有用？** 没有这个度量，drill 就是个安慰剂按钮。

**设计：**

- 配对规则：一个 `drill` 会话与其后同技能的 `verification` 会话（或任一场正式面试中该技能的下一个样本）构成一对。
- 度量：`练习有效性 = 验证等级 ≥ 练习前等级 的对数 / 总对数`，显示在 readiness 卡："最近 3 次'练→验'：2 次有效"。
- 无配对数据时显示"完成一次'练→验'后，这里会告诉你练习是否有效"。
- 数据全部来自现有会话样本（按 session_kind 过滤配对），纯派生。

**战略意义：** 这是这个系统相对通用 agent 的又一护城河——通用 agent 不会替你记住"你上上周练过什么、这周验证了没有"。

## 前端（画像页改造）

- 首屏：面试日期设置（内联日期选择，未设时显示"设置面试日期，开启每日训练"）+ 今日训练卡（取代 readiness 卡的独占位置，readiness 移入卡片内）。
- 技能卡：等级 + 新鲜度徽章 + 目标线水平条（已有）+ 趋势轨迹（已有）+ 已学角标 + 可展开证据链。
- 薄弱项区：排序规则升级（薄弱 × 生疏 × 未学优先），建议卡动作不变（已有练/验按钮）。
- 契约测试同步。

## 明确不做

- 跨场折线图库（快照 3 个，画了是噪声；sparkline 够用）
- 周报/邮件推送（本地工具没有触达渠道）
- 遗忘曲线的数学建模（艾宾浩斯公式是伪精准——三档新鲜度 + 衰减折算已经产生正确的行为动机）
- LLM 生成计划（纯规则可解释、零成本、每次打开重算）
- 学习标记影响等级（学过≠会了，原则不破）

## 验收标准

1. 技能卡可展开证据链（最近 3 次回答可追溯），薄弱未学排最前。
2. 新鲜度徽章正确：>10 天未练的技能显示"生疏"，readiness 衰减生效。
3. 设置面试日期后，首屏出现今日训练卡且动作与薄弱状态一致；无日期时不显示。
4. 练→验配对度量在完成一次 verification 后出现。
5. 学习标记不计入等级（回归：画像聚合测试不变）。
